# Этап 3: тюрьма целиком на Rust — итоги

2026-10-20. Эталон — gorn-tli 83bb91c (1.0.32): `src/core/prison`,
`src/main/prison/ownAdvisor.ts`, `src/cli/prison-*.ts`.

## Итог

Тюрьма перенесена целиком, и весь путь совпадает с эталоном до бита:
движок, стратегия, решатель, распознавание, память забега, советник,
подсказки, аудит. Настройка советника (`tune`, `play`, `solve-bench`,
`replay`, `audit`) теперь может идти в GornNext.

Решатель в одном потоке делает в 2,8–2,9 раза больше раундов за тот же
бюджет, чем эталон; regret совета в одном потоке — 0,0026 против 0,0041
у эталона, на 4 потоках — 0,0011 (эталон на 4 потоках — 0,0019).
Самоигра с решателем на 800 сидах (ход в ход одинаковая) — 173 с против
457 с у эталона на 16 процессах.

Две находки по дороге — обе про точность переноса, не про правила:

- **Эталон обновился посреди этапа до 1.0.32**: правка «Рог не засчитывает
  скачок Молота» (0201290). Сверка советника её поймала — одна партия из 64
  в решателе на кадре 20.10 00:09:17 (Рог против Вина при Молоте);
  правка перенесена в `policy/instant.rs`.
- **Чтение за границей таблицы ценностей.** Адаптер ставит ряд решений и на
  камеру надзирателя без узника; Замена тогда считается для редкости −1. В
  эталоне `val[-1]` — undefined → NaN, стратегия выбирает «Завершить
  день»; Rust падал. Теперь `val_js` даёт NaN, как JS.

## Замеры

Ryzen 7 7800X3D (8 ядер / 16 потоков), Node 24.16, rustc 1.99.1, release
(lto, codegen-units = 1), переносимая сборка. Игра закрыта, замеры этапа 1
закончены, параллельной нагрузки нет.

### Решатель: раундов за бюджет

`solve-bench --games 18 --positions 580 --rate` — 116 позиций (каждая
5-я), без остановки; медиана по позициям (у концовок раундов в десятки
раз больше — они раздувают среднее).

| | за 300 мс, медиана / p10 | за 1,5 с, медиана / p10 |
|---|---|---|
| TS, 1 поток | 1 444 / 617 | 9 847 / 3 611 |
| Rust, 1 поток | **4 065** / 1 459 (×2,8) | **28 487** / 9 544 (×2,9) |
| Rust, 2 потока | 6 728 / 2 564 | 44 312 / 15 644 |
| Rust, 4 потока | 13 264 / 4 864 | 79 232 / 28 560 |
| Rust, 16 потоков | 37 568 / 15 808 | 216 416 / 96 960 |

Для сравнения — этап 1 (пул worker_threads в gorn-tli): 1 843 / 3 981 /
~7 500 раундов за 300 мс при 1 / 2 / 4 потоках. Rust на одном потоке
быстрее эталона на четырёх.

Пул rayon играет раунды пачками по 2 × потоков и сливает их по порядку;
на коротких позициях (концовки) накладные пачек заметны: среднее на 2
потоках ниже, чем на одном. Медианы растут почти линейно.

### Решатель: regret

`solve-bench --games 18 --positions 580 --regret` — совет как в потоке
подсказок (показ через 300 мс, досчёт до 1,5 с, выбор орудий — до 4 с и
≥ 1500 раундов, правило смены), против эталона — той же Монте-Карло на
20 000 раундов (зерно 900000+i). Эталон посчитан Rust за ~3 мин на 16
потоках; оценки решателей совпадают до бита, поэтому файл годится и для
gorn-tli (тот же формат JSON).

| | regret решателя | мгновенной | первый совет, медиана / p95 |
|---|---|---|---|
| TS, 1 поток | 0,0041 | 0,0420 | 115 / 300 мс |
| Rust, 1 поток | 0,0026 | 0,0420 | 46 / 300 мс |
| Rust, 4 потока | **0,0011** | 0,0420 | 16 / 300 мс |
| Rust, 16 потоков | 0,0014 | 0,0420 | 6 / 162 мс |

Этап 1 в gorn-tli: 0,0034 / 0,0027 / 0,0019 при 1 / 2 / 4 потоках.
Разница 4 и 16 потоков — в шуме (по фазам: 7 позиций тропы дают половину).

### Самоигра с решателем, 800 сидов

Сиды 777000+g, тема g % 5 (как `prison-solve-bench --play`). Без срока —
правило остановки по умолчанию, потолок 300 раундов на ход: партии TS и
Rust одинаковы ход в ход, время — чистая скорость.

| | время | мгновенная | с решателем |
|---|---|---|---|
| TS, 16 процессов | 457 с | 7,936 | 9,044 |
| Rust, 16 потоков (партии параллельно) | **173 с** (×2,6) | 7,936 | 9,044 (+1,107 ± 0,083) |
| Rust, 1 поток (100 сидов) | 2,4 с на забег | | |

Режим приложения (показ через 300 мс, досчёт до 1,5 с, выбор орудий до 4 с),
Rust, 16 партий параллельно, решатель на партию — один поток: **9,220**
против 7,936 у мгновенной (+1,284 ± 0,083), 783 с. Тот же прогон эталона
на этих сидах начат и остановлен по решению пользователя: выигрыш Rust по
скорости уже ясен, сравнение силы — в живой игре. Для ориентира: A/B
этапа 1 (1 200 забегов, сиды те же, 16 процессов) — 9,13 у решателя на TS.

## Что не сделано

- **PGO и SIMD** (пункт 4 задания) — отложены: скорость уже в 2,6–2,9 раза
  выше эталона, а прирост от znver4 (+38 % на этапе 2) говорит, что PGO на
  переносимой сборке может дать ещё заметно. Замерять вместе со сборкой
  приложения.
- Пул rayon на коротких позициях: пачки дают накладные (среднее раундов на
  2 потоках ниже одного). Проще всего — постоянные потоки с общим счётчиком
  раундов, как в пуле этапа 1.
- Решатель в `replay`/`audit` пока однопоточный (как в эталоне по
  умолчанию); пул советнику — полем `OwnAdvisor::pool`.
